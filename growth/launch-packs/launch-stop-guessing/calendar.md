picked a launch date yet, so every row below is a **T-day offset** (T =
launch day, the day the ebook goes live at $0.99 and KDP Select starts).

offset in this file as a scheduled date.

calendar can actually run until the author has done a full read-through
and set `verified: true` themselves (`books/CLAUDE.md` §1). This calendar
is the execution plan for the day that happens, not a signal that it
already has.
