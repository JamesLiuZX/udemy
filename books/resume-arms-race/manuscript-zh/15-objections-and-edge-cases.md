# 反对意见与边缘情况

马库斯把本书前三章的想法带进了一场和他的人才招聘负责人的会议，本以为会得到热烈的响应，结果得到的却是又快又具体的反对。"我们一个岗位现在就已经收到四百份申请了。你是想让我们给每个招聘需求都写定制的面试问题？"他的经理这么问没有错，如果因为底层理念是对的，就打发掉这个问题，那才是一个错误。真实的约束理应得到真实的答案，而不是把同一个论点用更大的音量重复一遍。

本章收集了当有人试图把本书付诸实践时，通常会引发的那些反对意见，是那些出于诚意的反对，而不是恶意刁难，并且准确指出本书哪一部分已经给出了对应的答案。

## 速查表

| 反对意见 | 简短回答 |
| --- | --- |
| "我们没时间做结构化面试" | 第五章的评分表增加的是几分钟，不是几个小时：四个书面问题加一个一到四分的量表，同一个招聘需求里的每位候选人都重复使用，不用每次重新搭建。真正的时间成本在于写一次，而不是反复运行。 |
| "我们的ATS（申请人跟踪系统）供应商已经说过它做过偏见测试了" | 供应商对自家工具的说法，不能替你转移第七章所说的法律责任，而且供应商关于"经过验证的预测性特征"的说法，有据可查地经常经不起推敲。要自己核实，不要只信营销页面上的话。 |
| "候选人反正会适应我们接下来做的任何事" | 没错，但这不是停下来的理由。第一章的整个论点就是这件事没有一个稳定的终点；目标是把审查的重心移到眼下最难作弊的地方，而不是打赢一场本来就不会结束的战争。 |
| "这在我们的体量下行不通" | 第四章和第五章都展示了萨娜的压缩版本：一个只有三个固定问题的十五分钟电话初筛，而不是马库斯那套更长的流程。把这套纪律缩小，而不是取消。 |
| "用人经理只想快点推进" | 结构化流程不会自动变慢；第五章那套四问题的形式，花的时间和马库斯以前那套非结构化面试差不多。它去掉的，是那种没人能说清楚自己为什么喜欢某个候选人的复盘争论。 |
| "我们已经禁止AI写的简历了，这不是更简单吗" | 是更简单，但没法真正执行，而且很可能因为一种行为而拒掉相当一部分、而且还在增长的真正优秀的候选人，而第九章早就说明，大多数招聘人员真正想清楚之后，其实并不反对这种行为。 |
| "这些额外的记录工作，不就是官僚主义吗" | 第八章那套做法，每位候选人花不到一分钟，而正是它，能在关键时刻把"我大概确定"变成一个真正站得住的答案。不做记录的代价不是省下工作量，而是同样的工作量，日后要在更糟糕的条件下重新做一遍。 |
| "我的用人经理不会坐下来听这方面的培训" | 第十章的版本根本不是一场培训：一份附在招聘需求上的一页简报，加上面试小组开始前的五分钟，每次都重复使用，不用每个招聘需求都重新搭建或重新教一遍。 |
| "工作样本测试在我们的体量下批改起来太费时间" | 第十一章的做法，和第五章的评分表用同样的方式扩展体量：一份简短、结构化的评分标准，对照一份固定的参考答案，几分钟就能批改完，而不是一场没有边界的带回家马拉松。 |
| "内推不需要这种程度的审查，我们已经信任他们了" | 这正是第十二章的核心观点：出于人情的信任是一个真实、有用的信号，但不能替代用核实其他任何候选人说法的同一套方式去核实它。 |
| "身份诈骗是新闻里的问题，不是我们的问题" | 这正是第十三章的观点：罕见，真实存在，而且用一轮实时面试加一次真正的追问就能低成本防范。加上这一步的成本很小；一旦漏过一个真实案例，代价就不小了。 |
| "我们没时间给每个人都写拒信" | 第十四章的底线不是"每个人"：是给通过第一轮筛选的人一封及时的模板信，给任何面试过的人一段简短的个人留言，内容取自你已经在保持的第八章那份记录日志。每位面试过的候选人花十分钟，而不是给四百个人每人写一封定制信。 |

## 认真对待"我们没时间"

这是最值得耐心对待的一条反对意见，因为它背后的时间压力是真实的，不是想象出来的。不过值得给它配上一个数字，因为"没时间"这种说法，往往是拿错误的基准在衡量。

[KEY-INSIGHT: SHRM（美国人力资源管理协会）的《2025人才招聘基准报告》显示，美国非高管岗位的平均单次招聘成本为5475美元，高管岗位为35879美元，比2022年上升了21%，平均招聘周期在一个半月左右。相对于一个本来就要花费数千美元、大约六周时间的流程来说，一份书面评分表（第五章）或一条一行字的记录习惯（第八章）所增加的边际时间成本，只是每位候选人几分钟而已，不是一个叠加上去、明显更大的新项目。 || Source: Society for Human Resource Management, "2025 Talent Acquisition Benchmarking Report," released Oct. 15, 2025.]

"我们没时间"这句话诚实的那个版本，通常说的不是总的时间预算，这份数据已经表明，总预算本来就相当可观。它说的其实是谁来承担那增加的几分钟，往往是招聘人员本人，而不是那个因为招对了人而受益的组织。

[PULLQUOTE: "我们没时间"这句话诚实的那个版本，通常说的不是总的时间预算，这份数据已经表明，总预算本来就相当可观。它说的其实是谁来承担那增加的几分钟，往往是招聘人员本人，而不是那个因为招对了人而受益的组织。]

这是一种真实的、值得说出来的摩擦，而答案不是"反正照做就是了，别抱怨"。答案是让这份边际成本变得可见，并且小到能在一个真实繁忙的工作周里存活下来：用四个固定问题取代每个招聘需求都要定制的面试小组，用一行记录取代一份叙述性报告。

## 认真对待"我们的供应商已经处理好这个问题了"

如今在售的每一款筛选工具，营销页面上都会带着某种版本的"经过偏见测试""已验证""合规"之类的说法。把这类说法照单全收，而不是把它当作你自己核实工作的起点，有据可查地一再造成不良后果。

[KEY-INSIGHT: HireVue是使用最广泛的视频面试筛选平台之一，它在2021年1月停用了面部分析评分功能，起因是电子隐私信息中心（Electronic Privacy Information Center，即EPIC）向FTC（美国联邦贸易委员会）提出的正式投诉，以及工业组织心理学家们持续不断的批评。该公司自己的CEO承认，面部数据对预测准确度的贡献"微乎其微"，在大多数岗位上大约只有0.25%，尽管这项功能此前一直被宣传为能够测量候选人的认知能力、情商和心理特质。 || Source: SHRM, "HireVue Discontinues Facial Analysis Screening," Jan. 2021; Electronic Privacy Information Center, HireVue FTC complaint materials.]

这里的教训不是说每个供应商都在恶意行事；HireVue自己的说法，把这件事定性为善意的过度延伸，而不是故意欺骗。真正的教训是，供应商关于自家工具有效性的说法，不能替代你自己按第七章的方法，去审计这个工具在你的招聘流程里、在你的候选人身上、对照你自己的结果，实际表现如何。"供应商说没问题"回答的是一个关于他们营销内容的问题，不是一个关于你自身法律风险的问题。

## 认真对待"候选人反正会适应我们接下来做的任何事"

这一条值得一个直接、诚实的回答，而不是回避，因为它是真的。今天行之有效的结构化面试形式，最终也会被研究、被提前准备，就像任何一种筛选方法最终都会经历的那样。这不是本书这套建议独有的缺陷。这正是第一章所指出的整个问题的形状：两套系统彼此适应，看不到稳定的均衡点。

回应的方式不是假装这种动态会停止。而是去注意它真正意味着什么：目标从来就不是一劳永逸的胜利，因为第一章早就说明，没有任何人能得到这种胜利。目标是把审查始终放在眼下最难作弊的地方，而这个地方会随时间移动，就像一个优秀的编辑始终在检查一份稿子当下真正的失败点在哪里，而不是永远死守某一个特定的段落。什么都不做、指望简历体量问题自己解决，从而被动地输掉这场军备竞赛，比留在一场没有终点的竞赛里更糟糕，因为至少留在竞赛里，大多数时候优势还站在你这一边。

## 认真对待"这在我们的体量下行不通"

这条反对意见值得单独成节，而不只是表格里的一行答案，因为体量是隐藏在大多数其他反对意见之下的那个根本问题，而且它还在恶化，而不是趋于稳定。Employ的2025年招聘基准报告，追踪了大量真实雇主数据的样本，发现每个岗位发布的平均申请数，在2025年上升到了257.6份，高于前一年的207.2份，一年之内每个岗位平均多收到了大约五十份申请。第一章里马库斯的四百份，并不是一个极端的例外。它更接近整个市场正在走向的方向。

诚实的答案不是说本书的每一项技巧，都能原封不动地适应那种体量。而是这些技巧本来就不打算在每个阶段都以同样的方式运行。第四章的三项测试式阅读，是为快速过一遍整个候选人队列设计的；第五章的结构化评分表，是为那真正进入面试的十几个人设计的，即便申请体量翻了三倍，这个数字的增长方式也和申请体量不一样。那些最耗时的技巧，五分之四法则的检查、工作样本测试、记录习惯，都用在漏斗最窄的那一端，而不是最宽的那一端，这正是为什么即便漏斗顶端不断变大，它们依然能塞进一个真实的工作周。萨娜贯穿全书的压缩版本，存在的理由是一样的：体量改变的是你在每位候选人身上花多少时间，而不是底层纪律是否依然适用。

## 提前准备好你自己的答案

从本章的表格中，选出你预计接下来会在与你自己公司真实利益相关者的真实对话中，具体听到的那条反对意见。在那场对话发生之前，用你自己的话把真正的答案写下来，而不是等到对话进行中才想，这和第八章要求你在压力之下重建一个筛选决定之前，先把它记录下来的纪律是一样的。

一个在压力之下临时想出来的答案，往往会默认退回到一句安慰，"会没事的，相信我"，而不是本章为上面每一条反对意见都示范过的那种具体的、可核实的论述。如果你还没有属于自己的那个具体论述，这就是一个值得在会议之前补上的真实缺口，而不是等会议到了再临场发挥的理由。

[TAKEAWAYS]

- 大多数针对把本书付诸实践的反对意见，都是对一个真实约束的诚实反应，而不是对底层理念的抵触。要具体地回应那个约束，而不是笼统地回应那种抵触情绪。
- "我们没时间"通常是拿错误的基准在衡量。平均一次招聘，本来就要花费超过5000美元和六周时间；一份书面评分表或一条一行记录，增加的是几分钟，而不是一个额外的项目。
- 供应商关于自家工具有效性的说法，不能替代你自己的审计。HireVue自己停用的面部分析功能，就是一个有据可查的案例：一个听起来"已经过验证"的说法，最终没能站得住。
- 第一章所说的这场军备竞赛没有终点，但这不是停下来的理由。这是一个理由，让你不断把审查移到眼下最难作弊的地方，而不是死守一个已经被摸透了的方法。

[/TAKEAWAYS]
