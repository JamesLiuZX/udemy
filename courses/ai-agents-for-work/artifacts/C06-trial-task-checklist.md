# Trial Task Checklist

*From AI Agents for Your Job. Run this before any agent leaves the Trial rung of the trust ladder (Section 1.2).*

## Before you run it once

- [ ] The job description (C05) is filled in completely, ceiling included
- [ ] You have written down, in one sentence, what "correct" looks like for this specific run
- [ ] Test data is pinned and realistic: it includes at least one case that should trigger the agent and one that should not
- [ ] You know, before you look at the output, roughly what the answer should be

## Every run during Trial

- [ ] Read every single output. Not a sample. Every one.
- [ ] Compare it against your own answer, not against how confident it sounds
- [ ] Note anything invented: a fact, a name, a number, an owner, a date not actually given
- [ ] Note anything the agent should have caught and did not
- [ ] Log the result: pass, fail, or "correct but I'm not sure why"

## Deciding to move off Trial

- [ ] You have logged at least this many runs: __________ (fill in before you start; three to five is typical for a weekly agent)
- [ ] Every failure has a known cause, not just a shrug
- [ ] The failure rate is low enough that a Review-rung spot check (C07) would actually catch the rest
- [ ] Someone other than you (a second pair of eyes) has read at least one run's output

## The one question that overrides all of the above

**If this agent's worst plausible mistake happened right now, unreviewed, what would it cost?**

If the honest answer is "more than I'm comfortable with," it stays on Trial regardless of how clean the log looks. A trial period is not a formality to clear. It is the only evidence you have.
