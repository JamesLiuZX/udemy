@slide bullets
kicker: Carry these forward, not the tools
## The five ideas underneath everything you built

1. Write the job description before you touch a canvas
2. Judgement is the hard part. Triggers and routing are the easy part
3. Trial before trust, every time, no exceptions
4. Draft-only until an agent has earned the right to send
5. The honest number beats the impressive one

@narrate
If one of these five has to carry the rest, make it the third: trial before
trust, every time, no exceptions. Everything else in this course is a
technique. That one is the discipline that keeps the techniques from hurting
you.
