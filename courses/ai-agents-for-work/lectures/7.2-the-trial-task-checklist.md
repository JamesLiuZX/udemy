@narrate
Open the C06 template. It is short on purpose: a list you can actually
fill in during a coffee break, not a form that becomes its own chore and
gets abandoned by week two. Fill it in for the first agent you built,
Agent 1, before you move on, so the habit is real rather than
theoretical the first time you need it.


@slide bullets
kicker: What the checklist actually asks
## Three sections, in order

1. Before you run it once: job description complete, test data realistic, you know the expected answer
2. Every run during Trial: read everything, compare against your own answer, log invented facts
3. Deciding to move off Trial: a set number of runs, every failure explained, a second pair of eyes

@narrate
Notice section three asks for a number, not a feeling. Fill it in before
you start, the same way a real experiment sets its sample size in
advance. Three to five runs is a reasonable default for a weekly agent,
more for anything that touches a client directly.


@slide example
kicker: The one question that overrides everything else
::: example If this went wrong right now, unreviewed, what would it cost?
That question sits at the bottom of C06 for a reason. A clean checklist
does not override a bad answer to this question. If the honest cost is
high, the agent stays on Trial regardless of how many runs have passed.
:::

@narrate
This is the same instinct behind Agent 4's draft-only build in Section
6, applied to a moment in time instead of a piece of wiring. Both exist
because "it has worked so far" is never, on its own, a reason to stop
checking.


@slide bullets

## What to do now

1. Fill in C06 for one agent you have actually built in this course
2. Set your own run count, in writing, before your next trial run
3. Answer the cost question honestly, even if the answer is uncomfortable
