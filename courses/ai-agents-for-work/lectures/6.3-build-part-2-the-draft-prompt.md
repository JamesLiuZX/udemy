@slide definition
kicker: A new kind of ceiling

::: definition Tone is a constraint too
The first three agents you built controlled what got written. This one
has to control how it sounds, because a client reads it, not just Priya.
:::

@narrate
Add an AI Agent node after your Sheets node, attach your Gemini model,
and open the Prompt field. The User Message hands over every row that
made it through your filter: client, contact, renewal date, days
remaining. You are not writing the email yourself, you are handing the
agent the facts and trusting the system message to shape them properly.


@slide example
kicker: The system message for this build
::: example Read it exactly as you would type it
"You are a follow-up drafting assistant. For each row, draft a short,
polite chase email asking for outstanding renewal documents. Name the
client and the renewal date. Do not mention the premium amount. Do not
imply any penalty or threat. You are drafting only, never write as
though the email has been sent. If information is missing, draft
without inventing it."
:::

@narrate
Three sentences in that prompt are doing three different kinds of work.
One controls content: name the client and date. One controls tone: no
threats, no premium figure sitting in a client's inbox as a number they
did not ask for. One controls the agent's own self-understanding: it is
drafting, not sending, and it should never write as though it already
has.


@slide callout
kicker: Why the premium amount is banned from the email
::: callout A number a client didn't ask for reads like pressure
Even a neutral mention of "$18,400 renewal" in a chase email can land as
a nudge, whether or not you meant it that way. Cutting it costs you
nothing, because the actual renewal document already states it. This is
the same instinct as Section 1's blast radius, aimed at a sentence
instead of a system permission.
:::

@narrate
That is the whole prompt. It reads shorter than Section 5's, and it
should: the hard part of this build was never the writing. It was
deciding, in advance, exactly what a client should never see, and
saying so in one sentence rather than trusting the model to guess your
standards on its own.


@slide bullets
kicker: Before you move on
## What you should have now

1. An AI Agent node drafting one email per row that needs a chase
2. A tone genuinely safe to send to a real client, on inspection
3. Zero premium amounts, zero threats, anywhere in the output
