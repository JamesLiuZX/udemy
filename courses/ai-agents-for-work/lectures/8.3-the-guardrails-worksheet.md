@narrate
Open the C08 template. It is deliberately short, the same design choice
as C06 and C07: something you can actually fill in before you connect
a credential, not a form substantial enough to skip when you are in a
hurry. Keep it open while you build anything new for the rest of this
course, and honestly, after it too.


@slide bullets
kicker: What the worksheet actually asks
## Six questions, in order

1. What is actually being added, in one sentence
2. Does this change the scope: narrower, equal, or wider than before
3. What exact permission level does the new credential ask for, and is there a narrower option
4. Does the output need a human step, and can you name the exact node
5. The blast radius question, asked about the new piece specifically
6. Sign-off: four checkboxes, all of them, no exceptions

@narrate
Question two is where most trouble would get caught if people actually
asked it. "Wider" is not automatically wrong, but it means you are not
adding to a job description anymore, you are writing a new one, and it
deserves the same care as C05 did the first time.


@slide example
kicker: Worked example, before you see how it went wrong
::: example Filling it in for "a tool that checks for a reply first"
**What's added**: a search tool so the chaser checks for a reply before drafting.
**Scope change**: wider, if the credential covers the whole mailbox
instead of one label.
**Permission level**: check for a narrower, label-scoped option before
accepting the default.
**Human step**: none needed, the chaser is still draft-only downstream.
**Blast radius**: could read content outside the Renewals label if
scoped too broadly. That answer alone should stop you before you connect it.
:::

@narrate
Read that last line again. The worksheet, filled in honestly, would have
caught the exact mistake the next lecture is about, before it happened.
That is not hindsight. That is what the worksheet is for.
