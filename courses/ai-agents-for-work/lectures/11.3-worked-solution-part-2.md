@slide title
## Worked Solution, Part Two
kicker: Trial, guardrails and the honest number

@narrate
Pick up exactly where the last lecture left off: the checklist agent
built, wired and proven once against pinned data. What has not happened
yet is a real week watching it run against rows nobody chose in advance
for you. That is this lecture: a proper trial, the guardrails worksheet
answered honestly, and the number this agent would actually cost to keep
running.


@slide statement
kicker: Step four, filling in C06
## Five mornings, everything read before anything trusted

@narrate
Open the C06 template the same way you did back in Section 7.2, and fill
it in before a single real run happens: the same discipline as every
trial in this course. Test data was realistic, not invented: real column
values Priya's own colleagues actually type into that sheet. The
expected answer for each row was worked out by hand first, so the
agent's answer was something to check, not something to trust on sight.
And the run count was written down before the trial started: five
mornings, one working week, extended only if a miss ever went
unexplained.

The one question C06 asks that overrides the checklist itself, what
would this cost unreviewed, got an honest answer too. A missed document
surfacing only at renewal is an awkward phone call, not a lapsed policy,
because Agent 4's chaser and Priya's own weekly report both still catch
it from a different angle. That answer is what let a one-week trial feel
like enough, rather than something to extend indefinitely out of nerves.


@slide table
kicker: What five mornings actually looked like
## Three real outputs, one of them wrong

| Morning | Client | What the sheet said | Agent said | Correct? |
| --- | --- | --- | --- | --- |
| Monday | Oakfield Retail Group | drifted inside the 14-day window over the weekend, all three docs blank | MISSING: stock valuation, fire safety cert, signed renewal form | Yes |
| Wednesday | Brightwell Manufacturing | signed form arrived that morning by post | COMPLETE | Yes |
| Friday | Marlowe and Sons Fleet Services | fire safety cert cell read "Sent, awaiting review" | COMPLETE | No |

@narrate
Monday's run was the easy one. Oakfield had drifted inside the
fourteen-day window over the weekend, all three documents still blank,
and the agent flagged all three by name. Priya checked it against the
sheet herself and moved on inside a minute.

Wednesday told her something she already knew. Brightwell's signed form
had arrived by post that morning, someone had updated the cell, and the
agent correctly called it complete. Two clean passes in a row is exactly
the kind of run that tempts you to stop reading closely, which is
precisely why Section 7.1 warned against it.

Friday is the run worth actually stopping on. Marlowe's fire safety
certificate cell no longer read blank, it read "Sent, awaiting review,"
because a colleague in compliance had logged that the client's copy had
arrived but had not yet been checked against the policy wording. So why
would not blank versus not blank catch this, the same check you just
built into your own agent? Because that phrase is not blank, and the
system message never asked whether a cell said something specific, only
whether it said nothing at all. Anything non-blank read as received, so
the agent called it complete. Priya knew otherwise, because she had
spoken to compliance that same morning, and that is the only reason this
one did not slip through.


@slide statement
kicker: What changed after Friday
## One line added: only "Received" counts as received

lead: The trial found this. The prompt, on its own, would not have.

@narrate
Priya's fix was small, the same size as the fix Section 7.3 taught you
to expect. She added one sentence to the system message: only count a
document as received if the cell says exactly Received, and treat
anything else, including a hopeful note like "Sent, awaiting review," as
still outstanding.

Notice what you do not see happen here. Nobody rewrote the agent, nobody
added a second model to check the first one's homework. One person,
reading every output during a trial that was still actually running,
caught a gap between what a cell not being blank means and what a
document being received actually means. That gap is easy for you to
miss in the abstract and obvious the moment a real compliance note lands
in a real column of your own.

## C08, filled in for this specific build

::: example Filled from the C08 template
**What's added**: nothing new; reuses Agent 3's read-only Sheets
credential, scoped to the renewal pipeline range.
**Scope change**: equal, not wider. Three more columns on a sheet
already permitted.
**Permission level**: unchanged, read only, Get Row(s), the same as
Section 5.2.
**Human step**: none needed. The output is a flag Priya reads, never an
action.
**Blast radius**: nothing new. Honestly, the worksheet found no worry,
worth saying plainly rather than inventing one.
:::

@narrate
Fill this in honestly and sometimes the honest answer is that nothing
changed. This build did not need a new credential, a new permission, or
a new human checkpoint, because every piece of it was already something
Agent 3 had earned the right to touch. Priya still opened the Google
account's own consent screen and confirmed that, rather than trusting
her memory of what she had granted months earlier. That single check is
the reason you run the worksheet even when you are fairly sure of the
answer already: Section 8.3 asks the question by name instead of letting
you assume a scope stays put once it is set.


@slide example
kicker: Step six, the honest number
## C09, one plausible estimate for a fifth agent

::: example Filled from the C09 template
**Task replaced**: the ten minutes Priya used to spend each morning
cross-checking the pipeline against her memory of who still owed what
paperwork.
**Time now spent checking**: about two minutes, reading the flagged rows
before trusting them.
**Net time saved**: roughly 35 minutes a week, checking time already
subtracted.
**AI cost**: built and run on the same free Gemini tier as every
practice build in this course, so it costs nothing beyond the free
allowance Section 2.2 already covers. On a paid tier, a handful of short
calls like these would run to a few pence a day at most.
:::

@narrate
That estimate is exactly what it says it is: a plausible worked number
for a fifth agent inside a course, not a figure pulled off a real
invoice, because there is not a real invoice behind Priya's story. The
habit is the point, not the specific total. Count the task it replaces,
count the time you now spend checking instead of doing, subtract one
from the other, and write down what is left even when the number is
modest. A number like that survives a follow-up question, which is the
entire standard Section 9.2 set: not the biggest figure defensible, the
smallest one nobody can poke a hole in.

Say the sentence Section 10.1 taught you to say: this agent saves
roughly thirty five minutes a week chasing paperwork by hand, costs
nothing beyond what you are already spending on the other four, and
never marks a document received on its own, so every flag still gets a
human look before renewal day arrives.


@slide statement

kicker: What you just watched
## Six steps, one real task, nothing skipped.

lead: That is the whole method. You have now watched it run five times on Priya's week. Next, you run it once on yours.

@narrate
This build went faster than Agent 1 did back in Section 3, and it
should have. Every decision inside it, the shape of the trigger, the
wording of the ceiling, the two-line system message, was already a
decision made once before somewhere earlier in this course. What is
different by the fifth agent is not the difficulty, it is the amount of
it you no longer have to think about from scratch.

What is worth noticing is what did not get faster: the trial. Reading
Friday's output carefully took exactly as much attention as reading the
very first one back in Section 3.5 did, and it should, because that is
the one step in this method that speed is never allowed to shortcut.
That is the actual lesson of watching this run twice: the mechanics get
quicker, the checking never does.
