@slide definition
kicker: Same habit, third build

::: definition Count it yourself before the agent counts it for you
Five rows, pinned to the Sheets node: Brightwell Manufacturing at
$18,400, renewing 15 September, still open. Four other clients around
it, one already closed.
:::

@narrate
Before you run this agent even once, do the arithmetic in your head. Four
open renewals. A total premium you can add up on one hand. One renewal,
Dunmore Electrical, close enough to its date to flag. That is your
answer key.


@slide callout
kicker: What a pass actually looks like
::: callout Match the agent's report against your own count, line by line
Right number of open renewals. Right total premium. The right client
named as the one to watch. Anything else, however well written, is a
fail you caught for free, before it reached a director's inbox.
:::

@narrate
Run it against the pinned data and compare. If the numbers match, the
wiring and the judgement are both sound, for this snapshot of the sheet.
That phrase, "for this snapshot," is doing quiet work, and it is worth
sitting with for a second.


@slide statement
kicker: The sentence worth remembering
## A spreadsheet row is not a fixed fact. It is whatever is in that cell the moment the agent reads it.

lead: Today, that is exactly what you expect. It will not always be.

@narrate
This pipeline, these five rows, this exact Brightwell line, comes back
later in this course. Not because it changes here, but because
somewhere down the line, someone edits the sheet the agent reads from,
and the agent has no way to know that changed anything. Hold that
thought. Section 7 is where it matters.


@slide bullets
kicker: Before you move on
## What to do now

1. Run the agent against your pinned pipeline and check every number by hand
2. Note which row you would want double checked most, and why
3. Keep this exact pinned data. You will recognise it again

@narrate
With the wiring proven, next lecture connects this agent to a real
sheet and ships it.
