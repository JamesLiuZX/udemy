@slide statement
kicker: A different kind of question
## Agent 1 asked yes or no. This agent asks: which three sentences, out of two hundred, actually matter?

lead: Extraction is a harder judgement than classification, and your prompt has to work harder for it.

@narrate
Add an AI Agent node after your form trigger, attach a chat model the
same way you did in Section 3, and open the Prompt field. Set the User
Message to pull in your three form fields: meeting title, attendees, and
the transcript itself.


@slide example
kicker: The system message for this build
::: example Read it exactly as you would type it
"You are a meeting-notes assistant for Priya Malhotra. You are given a
transcript of a client renewal call. Extract only concrete action items:
things someone explicitly agreed to do. For each one, output a line:
[Owner] Action (due: date if mentioned, otherwise no date given). Do not
invent an owner, an action, or a date that was not stated. If there are
no clear action items, say so plainly. Ignore small talk."
:::

@narrate
Notice the shape of this prompt against Section 3's. That one told the
model what to ignore. This one tells it what it is not allowed to make
up. Both are the same habit, aimed at a different failure mode: an
inbox agent that over-flags is annoying, but a notes agent that
invents a deadline nobody agreed to sends someone chasing a promise that
was never made.


@slide two-col
kicker: Why the format line matters
## A loose instruction versus a strict one

::: cols
:: card bad
### "List the action items"
Some days you get a paragraph. Some days a table. You cannot build
anything reliable on top of an answer that changes shape.
:: card good
### "Output one line per item, this exact format"
Every run reads the same way, which means you, or a later automation
step, can trust it without checking the shape every time.
:::

@narrate
You are not being fussy by specifying the output format this precisely.
You are removing one more thing you would otherwise have to check by
hand, every single time this agent runs.


@slide callout
kicker: What this agent deliberately does not do
::: callout No memory, no tool, same as Agent 1
Each transcript is judged entirely on its own. Nothing here remembers
last week's call or reaches out to check a calendar. That is not a
missing feature, it is the scope from your job description, held to on
purpose.
:::

@narrate
With the prompt written, your agent can now read a transcript and
extract what actually happened in it. Next lecture proves that, without
spending a real AI call to find out.
