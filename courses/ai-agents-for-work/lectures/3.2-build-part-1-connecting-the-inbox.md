@slide quote
kicker: The wrong belief worth correcting
> I assumed the hard part of this would be the AI.

attrib: Almost everyone, before their first build

@narrate
It is not. You already did the hard part, the job description, back in
Section 1.4. What is left is mechanical, and this lecture is where you
prove that to yourself. Open a blank n8n canvas and click "Add first
step". The very first choice you get is a trigger, and for this agent
that trigger is one thing: a new email arriving. n8n calls the node
Email Trigger, IMAP.

Why does every build start at the trigger rather than the interesting
part? Because n8n will not let you start anywhere else, and its reason
is worth internalising: a workflow is a sentence that begins with
"when". When an email arrives. When Monday comes. Until you have
chosen the when, there is nothing for any later box to react to.
People who sketch the clever middle first end up with logic that has
no doorbell. Choose the doorbell first and the rest of the build has
somewhere to stand.


@slide sidenote
kicker: What IMAP actually means
## An old word for an ordinary thing

::: split
:: main
IMAP is the protocol almost every email provider speaks: Gmail, Outlook,
and any company mail server. You do not need to know how it works. You
need to know that this one node is how n8n reads any of them.
:: aside Two settings, that's it
Mailbox Name (which folder, "INBOX" by default) and Action (whether n8n
marks a read email as read). Everything else is the credential.
:::

note: TODO-IMG screenshots/section-3/n8n-imap-trigger-config.png (Email Trigger (IMAP) node panel: Credential, Mailbox Name, Action, Download Attachments, Format)

@narrate
This is a shorter configuration screen than most people expect from
their first node. Two visible settings, and one button: "Set up
credential." That button is doing the actual work.

Look at the Mailbox Name field and recognise it, because you have met
it before, on paper. This is the scope line of the job description
turned into a form field. Leave it on the default and the agent reads
everything that lands anywhere in the inbox. Type the name of one
folder, the way Priya types Renewals, and the trigger physically
cannot see past that folder's walls. One field, and the difference
between "reads my email" and "reads the one shelf I pointed at". If
your provider does folders as labels, same move, the label's name goes
here. Spend the thirty seconds to set it now, even on a practice
inbox, purely so the habit exists before the stakes do.


@slide table
kicker: What the credential form asks for
## Four fields, and where each one comes from

| Field | What it is | Where you get it |
| --- | --- | --- |
| User | Your email address | You know this one |
| Password | An app password, not your normal login | Your provider's security page, one minute |
| Host | Your provider's mail server address | The provider's IMAP settings page |
| Port | Almost always 993 | Same page; 993 with SSL is the norm |

note: TODO-IMG screenshots/section-3/n8n-imap-credential-form.png (IMAP account credential form: User, Password, Host, Port 993, SSL/TLS toggle)

@narrate
Gmail, Outlook and most providers publish these settings on a single
support page, and most ask you to generate an app password rather than
use your normal one. That is a good sign, not a hurdle: it means a
leaked n8n credential cannot log into your actual account settings, only
read the mailbox you scoped it to.

An app password, if you have never made one, is a spare key your
provider cuts for one specific app: a long generated string, shown to
you once, that works for mail access and nothing else, and that you can
cancel on its own without changing your real password. Generating one
takes about a minute on your provider's security page. At Calloway and
Finch the mail runs on a company server, so Priya's version of this
step was one message to the office IT contact asking for the host name,
the port and an app password for her account. If that is your
situation too, that one sentence email is the whole step, and it is a
normal request, not a strange one. Leave the SSL toggle on wherever
you see it: it simply means the connection travels encrypted, and
every provider expects it.

@slide bullets
kicker: What you should have now
## Before moving to the next lecture

1. An Email Trigger (IMAP) node on your canvas, credential connected
2. Mailbox Name set to the folder you actually want triaged, not just the default
3. A trigger box, not yet doing anything, because nothing is connected to it yet

@narrate
That last point is deliberate. A trigger with nothing downstream is not
a mistake, it is exactly where every build starts. But do not leave the
lecture without watching the trigger actually catch something. Use the
node's fetch test option to pull a recent email through, and look at
what appears: one row, with the sender, the subject and the body in
named columns. That is the wire table habit from Section 0 paying its
first rent. If the fetch comes back empty, the folder you named has no
mail in it, so send yourself a test message and fetch again. Thirty
seconds, and you have seen with your own eyes exactly what the next
lecture's agent will be handed. Next lecture connects the piece that
actually reads what lands here.
