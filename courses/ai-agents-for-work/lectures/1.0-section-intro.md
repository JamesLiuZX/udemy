## The One Idea
lead: An agent is an employee, not an app.

@narrate
You have already built one agent and watched it work. Before you build
three more, this section gives you the frame that makes the difference
between someone who gets hours back and someone who spends a weekend
cleaning up a mistake.

You already know this pattern from somewhere else in your life: a new hire
given the keys too early, a vendor trusted on a demo alone, a tool switched on
with the defaults left exactly as they came. Hold that memory for the next
twenty minutes. It's the same mistake this section exists to stop you making
with an agent.

Four lectures: what onboarding actually means, the trust ladder, the
blast radius, and the one document that ties all three together.
