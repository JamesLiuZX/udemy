@slide statement
kicker: The wrong belief worth correcting
## Most people think a weekly report agent should write prose. It should mostly do arithmetic.

lead: The writing is the easy part. Getting the numbers right is the job.

@narrate
Every Monday, Priya spends twenty minutes doing the same three sums
before she can write a word: how many renewals are still open, how much
premium is riding on them, and which ones are close enough to their
date to worry about. That twenty minutes of counting is what you are
about to replace, and if you run a pipeline of your own, you already
know exactly which sums you do by hand every week too.


@slide example
kicker: This agent's job description
::: example Filled from the C05 template
**The job**: summarises the renewal pipeline into three numbers and a
risk list, every Monday morning.
**Scope**: reads one sheet, Priya's renewal pipeline. Writes nothing
back to it.
**Action**: read only, output only. A draft report, never sent
automatically.
**Ceiling**: never marks a renewal as closed unless the sheet's own
Status column says so.
**Trial task**: three weeks, compared against Priya's own hand-counted
numbers each time.
:::

@narrate
That ceiling line reads like the one from Section 4, and that is not an
accident. Every agent you build in this course gets the same
instruction in a different costume: do not decide something the data
did not actually tell you. Write your own version of this template
before you open n8n, the same way you did for Agent 1.


@slide callout
kicker: Why the schedule matters here
::: callout This is the first agent that runs without anyone asking it to
Agents 1 and 2 waited for an email or a pasted transcript. This one runs
on a clock, every Monday, whether Priya remembers to trigger it or not.
That is a genuine convenience, and it is also the first time in this
course an agent acts on a timer instead of a prompt from a person.
:::

@narrate
Hold onto that distinction. Section 8's guardrails lecture comes back to
it directly: a scheduled agent needs the same ceiling as any other you
build, precisely because nobody is standing there to double check it
fired correctly. You will not be watching every Monday morning, and the
job description has to hold even when you are not.
