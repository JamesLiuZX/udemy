@slide statement
kicker: Why naming a failure mode matters
## A mistake you already have a name for is a mistake you catch in seconds. An unnamed one costs you an afternoon.

lead: Five names, five safeguards, all of them already built into agents you have shipped.

@narrate
You have already met every failure mode in this lecture, once each,
across the last four sections. This is the moment they get names, so
the next time one shows up in your own work, you recognise it
immediately instead of starting from confusion the way you might the
first time.


@slide table
kicker: The five, named
## What breaks, and what already catches it

| Failure mode | What it looks like | What catches it |
| --- | --- | --- |
| Invention | A fact, name or date that was never actually given | The "never invent" ceiling, Sections 4 and 5 |
| Scope creep | An agent reaching data outside its job description | The scope line, checked in Section 1.3 |
| Drift | A moved row, a changed structure, a quietly wrong answer | Spot-check question five, Section 7.4 |
| Tone failure | Correct facts, wrong feel, for a client-facing message | The tone constraint, Section 6.3 |
| Silent over-trust | Nobody has actually read an output in months | The sampling rate itself, Section 7.4 |

@narrate
Notice the last row does not describe the agent failing. It describes
you failing to keep checking. That is deliberately on this list, because
it is the single most common cause of a small mistake becoming a real
one, across every industry that has ever automated anything.


@slide two-col
kicker: Which agents are most exposed to which failure
## Not every agent risks every failure equally

::: cols
:: card bad
### Highest exposure
Agent 3 (drift, because it reads a shared sheet) and Agent 4 (tone, because a client reads the output)
:: card good
### Lower exposure
Agent 1 (invention risk is low, it only flags) and Agent 2 (contained to one transcript at a time)
:::

@narrate
This is worth knowing before you spend your limited checking time. Spend
more of it on the agents whose failure modes actually cost something if
they slip through, not evenly across all four out of habit.
