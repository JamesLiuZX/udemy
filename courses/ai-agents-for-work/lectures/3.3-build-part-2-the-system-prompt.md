@slide sidenote
kicker: Translating the jargon
## "Chat Model" is just the AI itself

::: split
:: main
n8n lists dozens of providers here: OpenAI, Anthropic, Google Gemini, and
smaller names beside them. Underneath the branding they all do the same
job for you, reading text and producing text back. You already chose
Gemini's free tier for this build back in Section 2.
:: aside Memory and Tool, skipped here
Memory lets an agent remember earlier messages in a conversation. Tool
lets it take an action, like searching the web. Your agent needs
neither: you are judging each email on its own, and it never acts, only
flags.
:::

@slide two-col
kicker: The one paragraph that does the real work
## User Message versus System Message

::: cols
:: card bad
### User Message
What this specific email says. Changes every single run.
:: card good
### System Message
Who your agent is and how it should judge. The same every run, written
once by you.
:::

note: TODO-IMG screenshots/section-3/n8n-agent-prompt-and-system-message.png (Prompt field with subject/from/body expressions resolved against a real email; System Message textarea with the triage instructions)

@narrate
You might expect this part to be complicated. It is really just you
writing down, in plain sentences, the same judgement Priya already makes
in her head every morning. The rule you are following: don't write
clever instructions, write honest ones.


@slide example
kicker: The actual system message used in this build
::: example Read it exactly as you would type it
"You are an inbox triage assistant for Priya Malhotra, a Client Services
Manager at a commercial insurance brokerage. For each email, decide if
it needs Priya's attention today. Flag it as urgent only if it is from a
real client and it concerns a renewal, a policy, a claim, a deadline, a
payment or a cancellation. Reply with one line: URGENT, with a reason,
or SKIP. Be conservative: promotional and internal messages are always
SKIP, even if they mention insurance topics in passing."
:::

@narrate
Notice what you did not write. No code, no special syntax, nothing an
engineer would recognise as a technique. Just a role, a decision, a
format for the answer, and one instruction about what to ignore. That
last sentence is doing more work for you than anything else in the
prompt. Leave it out, and you will find your model flags everything that
merely mentions the word insurance.


@slide callout
kicker: Where the User Message comes from
::: callout One field, three pieces of the email
Your Prompt field feeds the model the actual content: subject, sender
and body, pulled in with an expression referencing the trigger's output.
You are not typing the email in by hand. You are pointing at where it
already lives.
:::

@narrate
With both messages in place, your agent can now read an email and
decide. It cannot yet do anything with that decision. That is your next
lecture: routing.
