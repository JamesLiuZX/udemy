@slide statement

## The same discipline this whole course has asked of every agent, aimed at your capstone.

lead: Read this against your own build, honestly, the way Section 7 taught you to read an agent's output.

@narrate
This is not a quiz. It is the same five-question spot check from Section
7.4, aimed at the thing you just built instead of one of Priya's four.
Answer each one against your actual capstone, not against how you hope
it turned out. Get a coffee, read your own system message the way a
stranger would, and answer honestly. Nobody grades this but you.


@slide table
kicker: The rubric
## Five checks, pass or not yet

| Check | Pass looks like |
| --- | --- |
| Job description | C05 filled in completely, ceiling included, before you built anything |
| Scope | The agent can reach exactly what the job description says, nothing more |
| Judgement | The system message names what it should never invent or assume |
| Trial | At least one output read critically, checked against a known answer |
| Honest number | A real hours-saved and real cost figure, not an estimate you never checked |

@narrate
Five rows, five honest answers. A "not yet" on any of them is not a
failed capstone. It is exactly the kind of finding a spot check exists
to produce, and the fix is usually small: go back to the specific
lecture that row maps to and finish that one step. Most learners land a
clean pass on three rows and a genuine "not yet" on one, and that single
gap is usually more useful than five easy passes would have been.


@slide callout
kicker: The question underneath all five
::: callout Would you actually trust this running unsupervised next week?
If the honest answer is no, you have not finished the capstone yet, and
that is a completely legitimate place to be. Go back to Section 7.1 and
run a proper trial before you answer yes to yourself.
:::

@narrate
That question is the same one this entire course has been building
toward since Section 1's job description. It never goes away, no matter
how many agents you build after this one.


@slide bullets
kicker: Before you move on
## What to do now

1. Score your own capstone against all five rows, honestly
2. Fix whatever comes back "not yet" before you call it done
3. Keep this rubric. Use it on the next agent you build after this course ends, too
