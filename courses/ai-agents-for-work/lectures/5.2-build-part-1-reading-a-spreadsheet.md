## Two triggers, two different jobs

::: cols
:: card bad
### What you've built so far
Something happens, then the agent runs. An email arrives. A form is
submitted.
:: card good
### What this agent needs
Nothing has to happen. Monday morning arrives, and the agent runs anyway.
:::

@narrate
Search "Schedule Trigger" and add it to your canvas. Set the interval
to weekly, on Monday, at whatever time you actually want the report
waiting for you. This is the first trigger in this course that runs on
a clock instead of an event, and it is worth noticing how little
configuration that actually takes: one dropdown, one time, and you are
done.

@slide callout
kicker: One setting worth double checking
::: callout Get Row(s), not Append or Update
Google Sheets nodes can write back to a sheet just as easily as they can
read one. Your job description says read only, so make sure the
operation dropdown says "Get Row(s)" and nothing else. That one setting
is your entire ceiling for this node.
:::

@narrate
It is easy to skim past a dropdown when you are moving fast, and this is
the one dropdown in this build actually worth slowing down for. Get it
wrong, and read only stops being true no matter what your job
description says on paper.
