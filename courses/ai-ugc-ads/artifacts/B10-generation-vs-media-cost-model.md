# B10 · The Generation vs Media Cost Model

Part of *AI UGC Video Ads*. Built in lecture 9.2. The companion file is
`B10-cost-model.xlsx`: an empty workbook with the five-line model and a batch log.
Nothing in it is pre-filled, and this guide quotes no tool prices on purpose. Prices
in this category move fast, so the numbers are yours, from your own tools, dated.

Everyone worries about what the generator costs. Almost nobody worries enough about
what a bad decision built on top of it costs. Generation spend and media spend look
like the same kind of cost. They are not.

---

## 1. The five lines

| Line | What you enter or calculate |
| --- | --- |
| 1 | Cost per static (your tool's price) x images in one batch |
| 2 | Cost per UGC video (your tool and plan) x clips in one batch |
| 3 | Total generation cost for one batch: line 1 + line 2 |
| 4 | One day of testing: daily budget per ad set x number of ad sets (from B07) |
| 5 | Ratio: line 4 divided by line 3 |

If the ratio is large, generation is not your constraint. Testing discipline is.

## 2. How to use this

1. **Look up your own prices today** and write the date beside each. Keep a screenshot
   of the pricing page with the asset library (B06) so the number and its source never
   drift apart.
2. **Copy the daily budget and ad-set count from your testing worksheet (B07).** Do not
   retype them from memory.
3. **Fill the yellow cells and read the Reading cell.** It tells you which side of the
   ratio you are on.
4. **Never round line 3 to zero.** A batch that costs almost nothing still costs
   something. Tracking the real number keeps the model honest.
5. **Re-check prices every quarter.** The workbook flags a price dated more than 90 days
   ago.
6. **After each batch, log it** on the Batch log sheet: what you generated, what the
   generation cost, and the media you spent testing it. Over time that shows your own
   ratio, not a borrowed one.

## 3. What this model is not for

- It does not tell you whether to spend more on testing. That is decided from your
  margin (Section 7), not from how cheap generation is.
- It does not tell you to skip checks. Cheap generation is a reason to test more
  variants. It is never a reason to check them less carefully.

## 4. The trap

Because a remake is nearly free, it is tempting to skip the B05 pre-flight checks. The
remake is free. The media spend wasted before anyone caught the problem never comes
back, and a claim that oversteps, a rights gap on an avatar or a missing disclosure
costs you in policy strikes, not in generation fees.

## 5. An honest test

You have used this well if you can say, from the sheet alone: what one batch cost, what
one day of testing cost, the ratio between them, and the date each price was last
checked. If you cannot give the date, the model is already going stale.

## 6. Open gaps

- Prices, plan tiers and credit systems differ by tool and change often. This file
  holds none, so check each against the vendor's own pricing page.
- The model counts generation and test spend only. It leaves out your time, editing,
  talent and tool subscriptions beyond per-asset fees. Add them in the note column if
  they matter to your decision.
