# B01 · The Creative Brief System

Part of *AI UGC Video Ads*. Built in lecture 2.6, the Section 2 workshop, from
lectures 2.1 to 2.5. Use it to write one brief for one real product before any
prompt is written or any variant is generated, and to check every later idea
against it.

The brief answers questions before generation starts. It says nothing about
creative direction, tone or which generator to use. Those decisions belong to
later sections.

---

## 1. How to use this

1. **Pick a real product.** Your own store, a client's, or one you are studying
   closely enough to write about honestly, with a real price and a real
   audience. Not a hypothetical.
2. **Work in this order,** and keep to the time budget:

| Step | Time | What "done" looks like |
| --- | --- | --- |
| 1. Product truth | 15 min | Facts and a claims boundary, nothing else |
| 2. Awareness ladder | 10 min | Five rungs, one honest sentence each |
| 3. Hook matrix | 10 min | Patterns matched to rungs, not all six forced in |
| 4. Angle map | 20 min | Twenty rows, each checked against the reskin test |
| 5. Congruence checklist | 5 min | Your actual landing page checked against it |

3. **Do not stall on section 1.** If you are well past the sixty-minute mark and
   still on the product truth, move on. An imperfect ladder built on a good
   enough product truth beats a perfect product truth with nothing built on it.
   You can sharpen earlier sections once the whole document exists.
4. **Be honest that this runs closer to an hour,** done properly, not five
   minutes. It is paid once per product.
5. **Do not skip the claims boundary,** and do not write angles only for the
   rung that is easiest to write for. Both shortcuts cost more later, when the
   pre-flight check catches the same problem after variants have been
   generated.
6. **Keep it where you will see it.** A brief that is read only on the day it is
   written protects nothing. The value is in checking a new idea against it
   weeks later, quickly, without arguing the claims boundary from scratch.

## 2. Section 1: Product truth (lecture 2.1)

A narrow document. It holds facts and the claims boundary. It does not hold tone
or brand voice, angle ideas or hooks, or anything aspirational that is not yet
true.

| Field | Your answer |
| --- | --- |
| Product and variant | |
| Price | |
| Margin, and anything else a number depends on | |
| Provable spec: what you can defend without inventing a study. Give the source for each. | |
| What we can claim: exact wording, spec and fit statements | |
| What we cannot claim: exact wording of off-limits statements | |
| Who reviewed the claims, and when (a name and a date) | |

**Spec claims versus outcome claims.** A spec describes the product. An outcome
claim makes a promise about a body, a result or an endorsement. Only spec claims
belong in "what we can claim" unless you hold the substantiation.

| Statement type | Example form | Allowed |
| --- | --- | --- |
| Spec | A measurable, checkable property of the product | Yes, if provable |
| Fit or use | Who and what it is built for | Yes, if true |
| Outcome | A result promised to the buyer | Only with substantiation you hold |
| Endorsement | "Recommended by", "clinically proven" | Only with proof you hold |
| Invented statistics | Any percentage or number you cannot source | No |

The boundary exists so that a generator, or a tired copywriter at midnight, has
something firmer than "does this sound okay" to check a line against. Where a
claim touches health, safety, money or any regulated category, the person named
above checks it with qualified advice before it appears in an ad. This template
does not tell you what is lawful for your product or market.

## 3. Section 2: Awareness ladder (lecture 2.2)

Matching an ad to a rung means writing the one sentence the audience needs next,
not the one sentence you would most like to say. Write one honest sentence per
rung.

| Awareness level | What they already believe | What the ad has to do | Your product |
| --- | --- | --- | --- |
| Unaware | Has the problem, has not connected it to a category | Name the problem before selling anything | |
| Problem-aware | Knows the problem, not the category | Introduce the category as a real option | |
| Solution-aware | Knows the category exists | Say why your spec is the one that matters | |
| Product-aware | Knows your brand, has not bought | Answer the objection that is actually stopping them | |
| Most aware | Already a customer | Remind, do not persuade | |

Test: take an ad you have already run and guess which rung it was written for.
If you cannot answer in one word, it probably was not written for any rung.

## 4. Section 3: Hook matrix (lecture 2.3)

Six named patterns, matched to the rungs they work best on. Match what fits.
Do not force all six in. A fuller worked matrix is artifact B02.

| Pattern | What it interrupts | Works best on |
| --- | --- | --- |
| Problem-agitate | A feeling they have not named yet | Unaware, problem-aware |
| Direct address | "This is about you, specifically" | Problem-aware |
| Pattern interrupt | Scroll-speed autopilot | Any rung, cold especially |
| Spec proof | Scepticism about whether it works | Solution-aware |
| Myth-bust | An assumption they already hold | Solution-aware |
| Objection answer | The one thing stopping a purchase | Product-aware |

| Rung | Pattern | Your hook line | Names a real moment or a checkable number? |
| --- | --- | --- | --- |
| Unaware | | | |
| Problem-aware | | | |
| Solution-aware | | | |
| Solution-aware | | | |
| Product-aware | | | |

A specific hook names a real moment or a checkable number and is aimed at one
rung. "You deserve comfort" is aimed at no one. This matrix is a starting
hypothesis, not a verified fact. Only a test tells you which pattern earns its
rung.

## 5. Section 4: Angle map (lecture 2.4)

Twenty angles from three questions, asked once per rung, twice:

1. What does this person specifically feel or believe right now?
2. Which hook pattern from your matrix actually fits that?
3. What is the one proof point from your product truth that backs it up?

Five rungs, two honest answers each, twenty rows. Every proof point must come
from section 1, not from your imagination.

**The reskin test.** Read the rows side by side. A reskin has the same core
feeling in new words, the same proof point reworded, and the same rung with no
new question answered. A real angle has a genuinely different feeling or doubt,
a different proof point doing the work, and earns its own row. Do not settle for
twelve good rows and eight reskins.

An honest limit: a good map guarantees twenty different bets. It does not
guarantee twenty good ones. The pre-flight check and the test do that.

## 6. Section 5: Congruence checklist (lecture 2.5)

Run it on your real landing page, on a phone, the way a stranger would arrive.
The click and the page must feel like the same ad.

| Element | What breaks if it does not match | The ad says | The page says | Matched? |
| --- | --- | --- | --- | --- |
| Headline | The visitor re-reads to check they are in the right place | | | |
| Hero image | The visual promise from the ad is not continued | | | |
| Offer or price | A mismatch reads as bait and switch | | | |
| Proof point | The exact claim that earned the click goes unmentioned | | | |

If the fix is the page and you do not own it or cannot rebuild it in time, say so
plainly rather than blaming the ad. Check congruence before you write an angle
off for good: a losing result and a losing angle are not always the same thing.

## 7. Honest test

- Does the claims boundary list exact wording, with a named person who answers
  for it?
- Is every proof point in section 4 traceable to section 1?
- Do the twenty angles cover all five rungs, or only the easy ones?
- Are there genuinely twenty different bets, or twelve and eight reskins?
- Was the congruence check run on the real page, on a phone?
- Is the brief somewhere you will see it before approving the next idea?
