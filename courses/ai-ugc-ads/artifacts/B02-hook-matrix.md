# B02 · The Hook Matrix (Awareness Level x Hook Pattern)

Part of *AI UGC Video Ads*. Built in lecture 2.3 and downloaded at the Section 2
workshop (lecture 2.6). It is also the sheet you sort finished ads against in
lecture 5.3. Use it to write one hook line, aimed at one awareness level, for
each hook pattern that fits it, before you generate anything.

A fuller one-table version is Section 3 of the creative brief (B01). Use B01 to
set the product truth and the ladder, then this sheet to work the hooks in depth.

---

## 1. How to use this

1. **Start from the brief.** You need your product truth and claims boundary
   (B01, section 1) and your awareness ladder (B01, section 2). Every number or
   spec in a hook must come from the product truth.
2. **A hook is a targeting problem wearing a writing problem's clothes.** Its job
   is to interrupt one specific thought someone is already having. Get the thought
   wrong and no cleverness saves the line. Get it right and a plain sentence
   outperforms a brilliant one aimed at the wrong person.
3. **Do not try to write every row at once.** Start with the row that matches the
   rung carrying most of your current traffic. Write that line properly. Let the
   rest fill in.
4. **If you are unsure which rung most of your traffic is on,** start with the
   pattern interrupt. It is the one pattern that works whichever rung the viewer is
   on, because it is not arguing anything yet. It earns the half second the others
   need.
5. **Pick the pattern for the rung you are weakest on,** not the one you most like
   writing.
6. **Run the swap test on every line** (section 4) before it goes anywhere.
7. **Treat the matrix as a hypothesis.** Only a test shows which pattern earns its
   rung (Section 7 of the course).

## 2. The six patterns

| Pattern | What it interrupts | What it does | Works best on |
| --- | --- | --- | --- |
| Problem-agitate | A feeling they have not named yet | Names a feeling before it has been put into words | Unaware, problem-aware |
| Direct address | "This is about you, specifically" | Says "you, specifically" instead of speaking to everyone | Problem-aware |
| Pattern interrupt | Scroll-speed autopilot | Earns the half second without yet arguing anything | Any rung, cold especially |
| Spec proof | Scepticism about whether it works | Answers "does this actually work" with a number you can defend | Solution-aware |
| Myth-bust | An assumption they already hold | Takes something the audience believes and turns it around | Solution-aware |
| Objection answer | The one thing stopping a purchase | Meets the single hesitation of a warm viewer | Product-aware |

## 3. The matrix

One pattern per rung, not one pattern stretched across all five. Solution-aware is
the widest rung, so it earns two genuinely different bets rather than one guess
stretched across a crowd that does not think as one person.

Most-aware (existing customers) is deliberately not a row here. They are reached
through retargeting and email, not cold hook-driven creative. A retention matrix
would be a separate sheet.

## 4. The specificity checks

| Check | How to run it |
| --- | --- |
| The swap test | Could this line run for a completely different product with a five-word edit? If yes, it is generic, however good it sounds read aloud. |
| The moment test | Does it name a real moment a real customer recognises instantly (a specific hour, a specific situation)? |
| The number test | If it contains a number, is that number in your product truth with its source? |
| The one-rung test | Is it aimed at exactly one rung, or at everyone? |
| The claims test | Does it stay inside your claims boundary, with no outcome promise, no endorsement you do not hold, and no invented statistic? |

A line like "You deserve comfort" is true of almost every product ever sold, so it
is aimed at no one. "By hour eight" names an actual moment. Specificity is the
whole trick, and a generic prompt to a generator will quietly strip it out unless
you ask for it directly.

Note that a hook written for a generator needs the specific detail written into
the prompt. The checks apply to the line you give the tool, not only to what comes
back.

For example, a spec proof line often reads naturally as text over a static image
and can sound like a warning label when spoken flat by a video avatar. Sections 3
and 4 of the course cover the fix. Record what you find rather than assuming.

## 9. Honest test

- Does every hook line trace to a fact in your product truth?
- Did you start with the row that carries most of your traffic, or the easiest
  row?
- Could any line run for another product with a five-word edit?
- Is any "result" in the test log something you have not measured?
- Did you write the angle you would normally cut, and decide about it honestly?
