## Sam Had Eleven Hook Lines by Friday. None of Them Named an Actual Shift.
lead: The twelfth line was plainer than all of them, and it's the only one that survived a second read.

@narrate
By Friday afternoon Sam had eleven hook lines drafted for Harlan, each one a
little more clever than the last. Reading them back, he felt the problem
before he could name it: every line could have been written for almost any
product that promised comfort. Nothing in any of them named the actual
moment a real Harlan customer was standing in.

Line twelve was plainer. "Your feet don't have to feel like this by hour
eight." No wordplay, no twist. It named a specific hour on a specific kind
of shift, and it was the only one of the twelve that survived a second read.

Every ad lives or dies in about half a second, and that half second has a
name: the hook, the opening line or image that has to stop a scroll before
anything else in the ad gets a chance. Most people think a hook is a
writing problem. Write it sharper, punchier, funnier. It's actually a
targeting problem wearing a writing problem's clothes.

A hook's job is to interrupt one specific thought someone was already
having, the exact thought Sam's eleven drafts missed and his twelfth one
hit. Get the thought wrong, and no amount of cleverness saves the line. Get
it right, and a plain sentence outperforms a brilliant one aimed at the
wrong person.

@slide table
kicker: Six named patterns
## The hook taxonomy

| Pattern | What it interrupts | Works best on |
| --- | --- | --- |
| Problem-agitate | A feeling they haven't named yet | Unaware, problem-aware |
| Direct address | "This is about you, specifically" | Problem-aware |
| Pattern interrupt | Scroll-speed autopilot | Any rung, cold especially |
| Spec proof | Scepticism about whether it works | Solution-aware |
| Myth-bust | An assumption they already hold | Solution-aware |
| Objection answer | The one thing stopping a purchase | Product-aware |

@narrate
If you only take one pattern from this table into this week's batch, take
pattern interrupt. It's the only one of the six that works regardless of
which rung the viewer's on, because it isn't arguing anything yet. It's
just earning the half second everything else here needs in order to land
at all. Start there if you're not sure which rung most of your traffic
actually sits on.

If you want the full six-pattern breakdown: problem-agitate names a feeling
before it's been put into words, direct address says "you, specifically"
instead of speaking to everyone, spec proof answers "does this actually
work" with a number, myth-bust takes something the audience already
believes and turns it around, and objection answer meets the one hesitation
stopping a warm viewer from buying. But the decision that actually matters
this week is simpler than memorising all six: pick the one pattern that
matches the rung you're weakest on, not whichever one you personally like
writing.

One more flag: the five non-interrupt patterns don't transfer cleanly
across formats. Spec proof reads naturally as text over a static image;
spoken flat by a video avatar, the same line can sound like a warning
label. Sections three and four cover the fix.

@slide code
kicker: The artifact
## Harlan's hook matrix, awareness level by pattern

```text
UNAWARE          Problem-agitate
"Your feet don't have to feel like this by hour eight."

PROBLEM-AWARE    Direct address
"If you're on your feet 10+ hours a shift, read this."

SOLUTION-AWARE   Spec proof
"15 to 20 mmHg graduated compression. Not a guess. A spec."

SOLUTION-AWARE   Myth-bust
"Compression socks aren't just for flights. Ask anyone on a 12-hour shift."

PRODUCT-AWARE    Objection answer
"Still deciding? Here's what a nurse actually thought after week one."
```

@narrate
This is the actual artifact, and notice the shape of it: one pattern per
rung, not one pattern stretched across all five.

Each line traces straight back to the product truth document and the
ladder from last lecture. The spec proof line uses the exact number Dana
can defend. The objection-answer line assumes a real hesitation, not a
generic nudge to buy. Nothing here is clever for its own sake. Every line
is doing one specific job, for one specific person.

Notice, too, that solution-aware gets two rows instead of one. That's
deliberate: it's the widest rung, so it earns two genuinely different bets
rather than one guess stretched to cover a crowd that doesn't think as one
person.

And notice what's missing: most-aware, the top rung from last lecture's
ladder. Not an oversight. Most-aware audiences are existing customers,
reached through retargeting and email, not cold hook-driven creative, so
this matrix doesn't need a row for them. A retention matrix would.

If you're only testing one thing this week, don't try to write all five
rows at once. Start with whichever row matches the rung carrying most of
your current traffic, write that one line properly, and let the rest of the
matrix fill in as you go.

@slide two-col
kicker: What separates a real hook from noise
## Specific versus generic

::: cols
:: card bad
### Generic, feels like a hook
- "You deserve comfort"
- "The sock you've been waiting for"
- Technically true, aimed at no one
:: card good
### Specific, actually is one
- "By hour eight" names a real moment
- "15 to 20 mmHg" is a checkable number
- Aimed at exactly one rung of the ladder
:::

@narrate
Here's the tell that separates a real hook from something that only sounds
like one.

"You deserve comfort" is true of almost every product ever sold, which
means it's aimed at no one in particular. "By hour eight" names an actual
moment a real person on a real shift recognises instantly. Specificity is
the whole trick, and it's also the thing a generic prompt to a generator
will quietly strip out unless you ask for it directly.

Here's a fast test you can run on any hook before it ships: could this line
run for a completely different product with a five-word edit? If yes, it's
generic, no matter how good it sounds read aloud. "Hour eight" barely
survives that test for Harlan. It doesn't survive it at all for anything
else.

Run that same test on the eleven drafts Sam cut. Every one of them survives
a swap to a completely unrelated product with barely an edit, which is
exactly how he knew, before any data existed, that they weren't hooks yet.
They were just nice sentences.

kicker: The honest limit

::: callout Be straight about this
This matrix is a starting hypothesis, not a verified fact. ==Only the test
in Section seven tells you which pattern actually earns its rung==. Treat
it as your best twenty-variant guess, not gospel.
:::

@narrate
One honest limit before you build angles on top of this.

Everything on this matrix is an informed guess about which pattern fits
which rung, built from the ladder and the product truth document. It isn't
verified yet, and it shouldn't be treated as settled until a real test in
Section seven says so. The matrix earns you a better starting batch. It
doesn't replace the test.

It's worth remembering exactly why that matters, because it's the same
lesson from Section one, showing up again in a new place: a well-reasoned
guess about which pattern will win is still a guess. It's a much better
guess than a blank page, and it is still not the answer.
