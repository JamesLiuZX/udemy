## A winner doesn't fail. It wears out. Those look identical on a dashboard and require completely different responses.
lead: The same "12-hour shift" creative that won in Section 8.2 gets tired here, and the fix isn't the kill rule.

@narrate
Here's a genuinely confusing moment if you're not watching for it. A
winning ad set's numbers start sliding. Click-through drops. Cost per
acquisition creeps up. It looks exactly like the early warning signs
Section 7.2's kill rule was built to catch.

It isn't the same problem, and treating it like one wastes a genuine
winner. A losing ad set never worked. A fatigued ad set worked, then the
same audience saw it enough times that it stopped landing. The fix for
the first is killing it. The fix for the second is refreshing it.

Why does this distinction matter enough for its own lecture? Because
the wrong response is expensive in a specific way. Kill a genuine winner
by mistake and you've thrown away the one angle that already proved
itself, right when you needed it most. Refresh a genuine loser instead
of killing it, and you've spent effort dressing up an angle that was
never going to work regardless of how it's cut.

There's a practical fix for the moment of confusion itself: check
frequency before you decide anything. It's sitting right there on the
same dashboard that gave you the click-through drop. You don't need a
new tool, only a column you were probably already skimming past.

@slide table
kicker: How to tell them apart
## Same symptom, two different causes

| Signal | Never-worked loser | Fatigued winner |
| --- | --- | --- |
| History | Never cleared the kill rule | Genuinely won, per Section 8.2's tree |
| Frequency | Usually still low | Climbing, often past 3 or more |
| The fix | Kill it | Refresh the creative, keep the angle |

@narrate
Frequency is the tell that separates these two. A never-worked loser
dies early, before frequency has time to climb, because the kill rule
catches it. A fatigued winner has been running long enough, to the same
audience, for frequency to climb well past where a fresh ad set usually
sits.

That's the actual signal worth watching, not just the declining
click-through rate on its own. Rising frequency plus declining
performance, together, is fatigue. Declining performance with frequency
that never climbed is a different problem entirely, worth investigating
on its own terms.

Think about why frequency specifically does this. Every person in an
audience only has so much genuine curiosity about the same fifteen
seconds of video. The first view earns real attention. The fifth or
sixth view from the same person is mostly being ignored, or worse,
actively tuned out, and frequency is the number that tells you how many
of those repeat views have actually piled up.

This is the same mechanic across both platforms from Section five, even
if the exact dashboard column isn't labelled identically everywhere.
Whatever a given platform calls the number, you're watching for the same
underlying drift: the same audience seeing the same fifteen seconds too
many times. The label on the column changes. The audience running out of
patience for a cut it's already seen five times doesn't.

## The exact numbers, weeks apart

```text
FIRST TEST (Section 8.2)
2.6% CTR. Frequency low, audience still fresh. Winner.

WEEKS LATER
Frequency past 3.4. CTR down to 1.0%, close to the
old gut-era baseline. Same creative, same audience,
now genuinely tired.

RESPONSE
Not killed. Refreshed: same angle, new cut, sent
back through the same testing architecture.
```

@narrate
Here's the exact same winning creative, read again weeks later. Frequency
past three point four, click-through down to one percent, nearly back to
the pre-testing baseline it started so far above.

Notice what didn't happen: nobody killed this ad set. The angle itself
was never the problem, the same audience had simply seen this exact cut
enough times that it stopped earning fresh attention. The response was a
new cut of the same angle, not a new angle entirely, sent back through
the same isolated testing structure from Section seven to confirm it
still works.

Notice, too, that the new cut goes back through testing rather than
launching on faith. A refresh isn't automatically going to perform,
just because the underlying angle worked once. It earns its own winner
verdict from Section 8.2's tree, on its own merits.

What actually changes in a refresh cut, concretely? Not the claim, and
not the angle: that already proved itself, and re-litigating it would
waste the one thing this winner earned. What changes is the surface, a
different hook, a different pace, a different actor reading the same
underlying script from Section 4.5's assembly stage. The audience needs
a reason to look again. The argument doesn't need to change.

@slide callout
kicker: The honest watchlist

::: callout Be straight about this
Fatigue is predictable, not sudden. ==Watch frequency on every winner,
not just its performance. By the time CTR alone tells you something's
wrong, you've already been paying tired-ad prices for days==.
:::

@narrate
One honest habit worth building before your own first winner goes tired.

Fatigue doesn't arrive without warning. Frequency climbs steadily,
visibly, before performance actually cracks. Watching frequency
specifically, on every ad set currently winning, catches the trend
early. Waiting for click-through to confirm it means you've already
spent several days paying a fatigued creative's higher cost per
acquisition before you noticed anything was wrong.

Build this into the same weekly habit Section 7.3's naming system
already asked you to keep. A watchlist is only useful if you actually
look at it on a schedule, not just when a number happens to catch your
eye. Check frequency on every current winner once a week, the same
discipline you're already applying to spend and results.

There's a mirror-image mistake worth naming too. Don't refresh a winner
that isn't actually tired yet, just because its frequency ticked up
slightly. A small rise is normal as an ad set keeps running. Refreshing
reflexively at the first tick wastes production effort on a creative
that was still earning its keep, and it's the same impatience Section
7.4 already warned you against, aimed at a different decision. Watch for
the pairing this table describes, climbing frequency alongside genuinely
declining performance, not either signal alone.

Next lecture answers the question this one leaves open: when a winner
does go tired, do you refresh the exact same angle, or is it time to try
something genuinely new instead.

Worth sitting with one thing before you get there. Fatigue isn't a sign
anything went wrong. It's what success looks like after enough time has
passed, because the audience it worked on is a fixed, finite group of
people, and no creative reaches every one of them with the same force
forever. Treating a tired winner as a maintenance cost, something you
plan for from the moment an angle first wins, is a different posture
than treating it as a surprise failure to react to. One of those keeps
the account running smoothly. The other has you scrambling every few
weeks, wondering why a proven winner suddenly stopped working, when the
honest answer was sitting in the frequency column the whole time.
