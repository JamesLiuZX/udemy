## Platform Playbooks
lead: The same creative system, tuned per placement.

@narrate
Nothing in this section asks you to make anything new. Every ad you've
built so far already exists. What changes here is where it runs and how
it's cut for that placement, because a feed and a For You page don't
reward the same fifteen seconds for the same reasons.

Harlan's own set already proved this the hard way: the same brief
performed differently depending on where it ran, clinical framing winning
on one platform and the raw, unframed cut winning on another. Same
product, same claims boundary, two different answers to "what works
here".
